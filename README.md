# 🌐 Python Access Web Data

🎯 A hands-on mini-project collection that explores how to **interact with the web using Python** — from scraping websites, handling XML/JSON, to using sockets and geolocation APIs.

## 🔍 Overview

This repository is part of my Python certification training and showcases different ways to access and process data from the web using Python:

📁 **Project Files:**

| File Name | Description |
|----------|-------------|
| `Extract_last_name_from_URL.py` | Extracts the last name from a given URL structure. |
| `get_Plus_code_from_location.py` | Uses geolocation to get a Plus Code for a given address. |
| `json_using.py` | Loads and processes JSON data from web APIs. |
| `XML_project.py` | Parses and processes XML data from web sources. |
| `scraper.py` | Web scraper that extracts specific content from websites. |
| `socket_using.py` | Connects to web servers via low-level socket programming. |
